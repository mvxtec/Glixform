# Mailer logos

- `default.svg` (WordPress), `gmail.svg`, `brevo.svg`, `mailgun.svg`, `zoho.svg`: from
  [Simple Icons](https://simpleicons.org) (CC0), coloured with each brand's official hex value.
- `outlook.svg` (Microsoft), `sendgrid.svg`, `ses.svg` (AWS), `smtp2go.svg`: supplied by the
  project owner from the brands' official logo files.
- `other.svg`: envelope icon supplied by the project owner.

All product names and logos are trademarks of their respective owners; they are shown only to
identify which service a setting connects to.
