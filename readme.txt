Drag-and-drop form builder: build forms, collect entries and get email notifications.

== Description ==

Glixform lets you build contact and other forms without code.

* Drag-and-drop builder with text, paragraph, email, number, dropdown, multiple choice, checkbox and hidden fields
* Embed with the Glixform block or the [glixform id="123"] shortcode
* Entries stored in your database, with search, read/unread status and CSV export
* Email notifications with smart tags
* Confirmation message or redirect after submission
* Built-in spam protection (honeypot and time token)
* Accessible markup and works without JavaScript

== Installation ==

1. Upload the plugin to /wp-content/plugins/glixform and activate it.
2. Go to Glixform > Add New to build your first form.
3. Add the Glixform block to a page, or paste the form's shortcode.
